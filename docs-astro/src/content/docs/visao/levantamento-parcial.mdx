## Requisitos Funcionais

<div class="softex-process">
> Os requisitos funcionais definem **o que o sistema deve fazer** para atender às necessidades dos usuários
</div>

### **Objetivo 1** — Gestão de Usuários e Perfis

#### RF01 – Cadastrar usuários <span class="badge badge--alta">Alta</span>

<ul class="softex-list">
  <li>O sistema deverá permitir que os usuários se cadastrem utilizando o e-mail corporativo da Softex</li>
  <li>O sistema deverá validar se o e-mail informado pertence ao domínio da empresa</li>
</ul>

#### RF02 – Controlar permissões <span class="badge badge--alta">Alta</span>

<ul class="softex-list">
  <li>O sistema deverá controlar acesso por perfis</li>
  <li>Administradores devem poder definir restrições e exceções para agentes</li>
</ul>

### **Objetivo 2** — Reserva e Edição de Espaços

#### RF03 – Reservar locais de trabalho <span class="badge badge--critica">Crítica</span>

<ul class="softex-list">
  <li>O sistema deverá permitir reservar salas e estações</li>
  <li>O sistema deverá conferir disponibilidade e evitar conflitos antes de finalizar</li>
</ul>

#### RF04 – Editar reservas <span class="badge badge--critica">Crítica</span>

<ul class="softex-list">
  <li>O sistema deverá permitir atualizar, cancelar ou reagendar reservas</li>
  <li>O sistema deverá impedir conflitos e respeitar regras de negócio definidas</li>
</ul>

#### RF05 – Adicionar estações de trabalho <span class="badge badge--media">Média</span>

<ul class="softex-list">
  <li>O sistema deverá permitir adicionar estações de trabalho</li>
</ul>

### **Objetivo 3** — Visualização e Busca

#### RF06 – Visualizar mapa interativo da planta baixa<span class="badge badge--critica">Crítica</span>

<ul class="softex-list">
  <li>O sistema deverá exibir mapa da planta para consulta</li>
  <li>O sistema deverá identificar salas/estações disponíveis em tempo real</li>
</ul>

#### RF07 – Visualizar detalhamento de reservas <span class="badge badge--media">Média</span>

<div class="softex-process">
> Ao selecionar uma sala/estação, o sistema deverá exibir:
</div>

<ul class="softex-list">
  <li>**Usuário responsável** pela reserva</li>
  <li>**Localização** da sala/estação</li>
  <li>**Horário de início e término**</li>
  <li>**Descrição/uso** da reserva</li>
</ul>

#### RF08 – Filtrar Reserva <span class="badge badge--media">Média</span>

<ul class="softex-list">
  <li>O sistema deverá permitir filtrar reservas por dia</li>
  <li>O sistema deverá permitir filtrar reservas por período</li>
  <li>O sistema deverá permitir filtrar reservas por dia da semana</li>
</ul>

### **Objetivo 4** — Comunicação e Alertas

#### RF09 – Alertar sistemas internos da empresa <span class="badge badge--media">Média</span>

<ul class="softex-list">
  <li>O sistema deverá enviar confirmações e cancelamentos por e-mail e sistemas internos, como o Slack</li>
  <li>O sistema deverá alertar sobre conflitos de reservas</li>
  <li>O sistema deverá alertar sobre início iminente de reservas</li>
</ul>

### **Objetivo 5** — Relatórios e Histórico

#### RF10 – Gerar relatórios de histórico de ocupação <span class="badge badge--critica">Crítica</span>

<div class="fases-container">
  <div class="fase-item">
    <h4>Relatórios de Uso</h4>
    <p>O sistema deverá gerar relatórios de uso/ocupação por período e por sala/estação.</p>
  </div>
  
  <div class="fase-item">
    <h4>Análise por Espaço</h4>
    <p>O sistema deverá gerar relatórios detalhados por sala e estação.</p>
  </div>
  
  <div class="fase-item">
    <h4>Visão Organizacional</h4>
    <p>O sistema deverá disponibilizar visão geral e por unidade/ambiente.</p>
  </div>
</div>

## Requisitos Não Funcionais

<div class="softex-process">
> Os requisitos não funcionais definem **como o sistema deve funcionar** em termos de qualidade, performance e restrições técnicas
</div>

### Requisitos de Produto

#### RNF01 – Atualização em tempo real <span class="badge badge--critica">Crítica</span>

<ul class="softex-list">
  <li>As reservas devem refletir alterações instantaneamente para todos os usuários</li>
</ul>

#### RNF02 – Disponibilidade <span class="badge badge--alta">Alta</span>

<ul class="softex-list">
  <li>O sistema deverá garantir alta disponibilidade, especialmente nos horários de maior uso</li>
</ul>

#### RNF03 – Performance <span class="badge badge--alta">Alta</span>

<ul class="softex-list">
  <li>O sistema deverá ser performático em ações críticas (reservar e cancelar)</li>
</ul>

#### RNF04 – Rapidez <span class="badge badge--alta">Alta</span>

<ul class="softex-list">
  <li>O sistema deve ser rápido e responder prontamente às solicitações</li>
</ul>

### Requisitos Organizacionais (Portabilidade/Tecnologia/Processo)

<div class="softex-process">
> **Stack tecnológico definido:**
</div>

<ul class="softex-flow">
  <li><strong>RNF05</strong> — Front-end: <strong>Vue.js</strong></li>
  <li><strong>RNF06</strong> — Back-end: <strong>Python com Django REST Framework (DRF)</strong></li>
  <li><strong>RNF07</strong> — Banco de dados: <strong>PostgreSQL</strong></li>
  <li><strong>RNF08</strong> — Versionamento: <strong>Git</strong> com repositório no <strong>GitHub</strong></li>
  <li><strong>RNF09</strong> — Empacotamento/Implantação: <strong>Docker</strong> em <strong>AWS</strong></li>
</ul>

### Requisitos Externos

#### RNF10 – Compatibilidade <span class="badge badge--alta">Alta</span>

<ul class="softex-list">
  <li>O sistema deverá ter suporte a desktop e mobile</li>
  <li>O sistema deverá ser compatível com os navegadores <strong>Chrome</strong>, <strong>Firefox</strong> e <strong>Edge</strong></li>
</ul>

#### RNF11 – Acessibilidade <span class="badge badge--media">Média</span>

<ul class="softex-list">
  <li>O sistema deverá atender <strong>WCAG nível A</strong></li>
  <li>Navegação por teclado</li>
  <li>Contraste adequado</li>
  <li>Textos alternativos em imagens</li>
</ul>

#### RNF12 – Conformidade legal <span class="badge badge--critica">Crítica</span>

<ul class="softex-list">
  <li>O sistema deverá atender à <strong>LGPD</strong>: segurança, consentimento e uso adequado de dados pessoais</li>
</ul>
