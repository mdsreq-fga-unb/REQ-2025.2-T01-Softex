## Unidade 3

Durante a terceira unidade, a equipe concentrou seus esforços na elaboração dos artefatos essenciais de Engenharia de Requisitos: o Product Backlog Building (PBB), o User Story Mapping (USM) e o Diagrama de Caso de Uso (UC). Esses artefatos foram desenvolvidos de forma integrada, garantindo alinhamento entre objetivos do produto, funcionalidades e interação do usuário com o sistema.

### Principais Entregas

#### Product Backlog Building (PBB)

O PBB foi estruturado para mapear objetivos, responsabilidades, tarefas e funcionalidades com clareza, proporcionando uma visão organizada da evolução do produto.

# Unidade 3

Durante a terceira unidade, a equipe focou na implementação das funcionalidades do MVP, testes do sistema e validação com o cliente.

## Principais Entregas

#### Implementação do MVP

- Desenvolvimento das funcionalidades prioritárias
- Integração entre frontend e backend
- Testes unitários e de integração
- Deploy do sistema em ambiente de produção

#### Validação e Testes

- Testes de usabilidade realizados
- Correção de bugs identificados
- Melhorias de performance implementadas
- Documentação técnica atualizada

## Feedback do Cliente

#### Avaliação Geral

O feedback do cliente foi fundamental para o refinamento do sistema e validação das funcionalidades implementadas.

#### Pontos Positivos

- Interface intuitiva e fácil de usar
- Funcionalidades atendem às necessidades principais
- Sistema responsivo e com boa performance
- Design alinhado com as expectativas
